**IP addresses.**

Certain IP ranges are reserved for internal networks and can't be reached directly from the internet. These are called private IP addresses:

- `10.0.0.0` - `10.255.255.255` (anything starting with 10)
- `172.16.0.0` - `172.31.255.255` (172.16 through 172.31)
- `192.168.0.0` - `192.168.255.255` (anything starting with 192.168)

Everything else is public, meaning it's routable on the internet.

## Section: 2 - The network map

Here, we start by looking at the company’s network segmentation. The network is split into zones, different zones for different purposes.

So we use the query to check how many zones is the network divided into.

```sql
DeviceInfo
| summarize device_count = count() by vlan
```

Now to check the ip address of the domain controller we use similar query to check the VLAN “servers”.

We can use the following query to check which vlan the device is in.

```sql
DeviceInfo
| where ip_address startswith "10.10.1."
| project name, ip_address

##### project chooses which columns to show in the results. Here, it displays only name and ip_address; other columns in DeviceInfo are left out.
```
